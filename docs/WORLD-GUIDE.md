# 초심자용 장면 길잡이

각 장면의 설명 바로 뒤에 현재 선택과 관련된 세계관 소개와 용어 풀이를 표시한다. 길잡이는 처음에는 펼쳐져 있고, 사용자가 접으면 다른 장면에서도 접힌 상태를 유지한다. 모든 용어는 별도의 펼침 목록에서 다시 찾을 수 있다. 용어를 읽는 행위는 구성점이나 선택 상태에 영향을 주지 않는다.

근거는 이 저장소의 WORLD-RESEARCH.md와 ERAC.md, 현재 CYOA의 선택지다. 기관명과 라이카의 직책은 사용자 지정 프로젝트 설정을 우선한다. 원작의 옛 기관명이나 미정인 전쟁·국가의 상세 설정을 추가하지 않는다.

- 공상체의 기본 정의, 공상 오염과 시공간의 관계, 힘의 기원 분류, 정보 필터와 게이트위빙의 한계는 기존 원작 조사 기록을 따른다.
- 신비, 심상, 술식, 의식, 경계의 설명은 현재 선택지를 이해하기 위한 쉬운 풀이이며 원작의 엄밀한 전체 분류를 주장하지 않는다. 특히 심상의 방패 예시는 이미지를 설명하는 예시이지 능력 지급이나 원작 공식 기술이 아니다.
- 공명은 이 CYOA가 흔적과 표식의 반응을 설명하는 표현으로 한정한다. 잔류 공명 감지와 공명 표식은 기존 선택지와 마찬가지로 프로젝트 창작임을 본문에도 밝힌다.
- 성맥 접속자와 앵커의 세부 설명은 현재 CYOA의 선택지에 적힌 사용 방식에 한정한다.
- 대가는 서사상의 부담이고 구성점은 게임의 선택 자원임을 구별한다.

문장 교정에서는 선택 ID, 비용, 선행 조건을 유지한다. 결과 서사는 배경·직업·사건·힘의 기원별 summary 문장을 사용해 선택지 제목을 무리하게 이어 붙이지 않는다.
