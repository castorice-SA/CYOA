# Laika CYOA

Laika 세계관에서 플레이어가 ERAC 조사 1팀에 합류하는 경위를 만드는 인터랙티브 CYOA입니다.

- 사이트: https://castorice-sa.github.io/CYOA/
- 저장소: https://github.com/castorice-SA/CYOA
- 기존 라이카 프로필: https://castorice-sa.github.io/Laika/

## 구성

나이 → 성별 → 살아온 환경 → 사건 이전의 직업 → 일상을 바꾼 사건 → 힘의 기원 → 당시 드러난 성격 → 팀이 주목한 능력 → 조사 1팀과의 첫 접점 → 합류 이유 → 함께 일하며 지킬 약속 → 첫 출근 장비 → 밝혀야 할 대가.

13개 장면에 109개 선택지를 제공하며, 각 선택지에는 배경과 의미를 설명하는 두 문단이 있습니다. 나이는 18~22세 / 23~29세 / 30~39세 / 40~49세 / 50~64세 / 65세 이상 중 하나를 선택합니다. 성별은 여성 / 남성 / 논바이너리 / 정하지 않음 중 하나를 선택하며 구성점과 다른 선택지의 조건에 영향을 주지 않습니다. 이름·코드네임 입력은 없고, 나이 숫자 입력도 카드 선택으로 대체했습니다.

한 번에 한 장면씩 선택하고 이전 장면으로 돌아가 수정할 수 있습니다. 사건과 첫 접촉에 따라 일부 합류 이유가 열리며, 선행 선택을 바꾸면 맞지 않는 합류 이유가 해제됩니다. 기본 구성점 8점, 대가에 따라 1~2점 반환 규칙은 유지됩니다. 마지막에는 선택한 만남과 동기를 연결한 합류 기록을 생성하고 복사합니다. 이야기는 첫 출근 시점에 멈추며 과거 사건의 진상이나 이후 조사의 결말을 확정하지 않습니다.

기존 버전의 직업·사건·능력·장비·대가·합류 선택은 가능한 범위에서 불러옵니다. 새 나이·성별·환경·약속 항목은 직접 선택하며, 과거 입력한 이름·코드네임·숫자 나이는 읽거나 출력하지 않습니다. 초기화 뒤에는 이전 선택이 다시 복원되지 않습니다.

선택한 카드는 해당 브라우저의 localStorage에 저장됩니다. 서버로 전송하지 않으며 기존 Laika 사이트의 저장 기록과 분리됩니다.

## 개발과 배포

HTML, CSS, JavaScript로 구성된 정적 사이트로 별도 설치나 빌드가 필요하지 않습니다. `index.html`을 열거나 정적 웹 서버로 실행할 수 있습니다. GitHub Pages는 `main` 브랜치의 루트를 배포합니다.

- `index.html`: CYOA 첫 화면
- `cyoa-data.js`: 장면과 선택지, 긴 설명, 선행 조건
- `cyoa.js`: 선택 규칙, 구성점, 개인 기록, 저장과 복사
- `cyoa.css`: 반응형 스타일
- `assets/`: 기존 프로젝트의 ERAC 문장과 배경 이미지
- `docs/`: 기존 세계관 조사 및 기관 설정

`node tests/choices.test.cjs`로 모든 나이·성별 조합의 완성 가능 여부, 구성점, 조건 해제 및 기존 저장 기록 호환성을 검사합니다.
