# 참고 CYOA에서 가져온 구조적 착안점

참고 페이지: https://stalight774.neocities.org/detectives_XXX/

참고 사이트는 사건 장면의 행동 선택, 인적 사항과 과거 이력, 능력과 대가, 목표와 판단 기준을 여러 단계로 나누어 진행한다. 조사 1팀 합류 CYOA에는 그중 **사건 뒤에 플레이어가 한 행동**, **함께 일할 때 부딪힐 평범한 습관**, **합류 제안을 듣고 직접 확인한 질문**을 장면으로 반영했다. 새 장면의 선택은 즉시 짧은 기록으로 나타나고 최종 합류 서사에도 이어진다.

참고 사이트의 세계관 문장·인물·능력·이미지·선택지 문구를 이 저장소에 복제하지 않았다. 기존 Laika / ERAC 설정, 해요체, 첫 출근에서 끝나는 범위, 성별 두 선택, 이름·코드네임 없음, 최종 문장을 유지한다.
